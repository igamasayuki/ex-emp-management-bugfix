## 1. 研修生のスタート地点（バグの状態）
研修生は、新しい機能の追加要望を見て以下のように考えます。
> 「検索窓で名前を入れるときに、候補が出てきたら便利だよね。でも、これって Java じゃなくて HTML（フロントエンド）の問題だよね？ そもそもどうやって実現するんだろう？」

**ここで、ボス（指導者）は「フロントエンドの技術選択」の視点を教えます。**

## 2. 指導者からの「気づき」の問いかけ
研修生に以下のように問いかけてみてください。
> 「こういう機能を作るとき、昔は Javascript のライブラリ（jQuery など）を使ってゴリゴリ書くしかなかったんだ。でも今は、HTML5 の標準機能だけでサクッと作れちゃったりする。この2つのアプローチ、どっちが良いと思う？」

研修生に、「外部ライブラリに頼る（カスタマイズ性重視）」と「標準機能を使う（軽さ・手軽さ重視）」のトレードオフ（一長一短）を考えさせます。

## 3. ロジックの組み立て方：2つのアプローチ
「今回は学習のために、両方のパターンを知っておこう。実務では要件によって使い分けるんだよ」と導きます。

1.  **【パターンA】HTML5 標準（datalist）**: とにかく簡単。追加の CSS も JS も不要。
2.  **【パターンB】jQuery UI**: 少し手間はかかるが、見た目や動きを細かく制御できる。

## 4. メソッド・文法の駆使（実際のコード）

### 【共通】バックエンドでのデータ準備（FullEmployeeController.java）
どちらの方式でも、まずは Controller から「全従業員名」のリストを画面に渡してあげる必要があります。

```java
// 全従業員の名前だけを抽出したリストを Model に詰める
List<String> employeeNames = allEmployees.stream().map(Employee::getName).collect(Collectors.toList());
model.addAttribute("employeeNames", employeeNames);
```

### 【パターンA】datalist 方式（list_datalist.html）
```html
<input type="text" name="name" list="employeeNames" class="form-control">

<!-- inputタグのlist属性と同じIDをつける -->
<datalist id="employeeNames">
    <option th:each="name : ${employeeNames}" th:value="${name}"></option>
</datalist>
```

- **文法解説（datalist）**:
    - HTML5 の標準タグです。`<select>` ボックスのように候補を持ちつつ、テキストの自由入力も許容する仕組みです。
    - 「ライブラリを読み込まなくていいので、ページが軽くてエラーも起きにくい」というメリットを伝えます。

### 【パターンB】jQuery UI 方式（list_JQuery.html）
```html
<input type="text" id="name" name="name" class="form-control">

<!-- jQuery UI の読み込みと設定 -->
<script th:inline="javascript">
    $(function() {
        // Thymeleaf を使って、Java のリストを JS の配列に変換する
        var availableNames = /*[[${employeeNames}]]*/ [];
        
        // jQuery UI の autocomplete 関数を呼び出す
        $("#name").autocomplete({
            source: availableNames
        });
    });
</script>
```

- **文法解説（th:inline="javascript"）**:
    - これは Thymeleaf の強力な機能で、Java 側の変数（`${employeeNames}`）を、JavaScript の変数（配列やJSON）として安全に埋め込んでくれます。
    - 「JavaScript と Java の架け橋になる機能だよ」と教えると分かりやすいです。

## 5. 研修生へのステップアップ課題
「今は画面を開いた時に『全員の名前』を読み込んでいるけど、もし従業員が 100万人 いたらどうなる？ ページを開くのがめちゃくちゃ遅くなるよね。それを解決するには、どんな技術（非同期通信など）が必要になるかな？」

と問いかけ、Ajax や Fetch API を使った「文字を入力するたびにサーバーに候補を取りに行く」高度なアーキテクチャへの関心を引きます。
