# (1-1) 初級 画面遷移 徹底解説

## 1. 研修生のスタート地点（バグの状態）
研修生は、既存のバグコードを見て以下のように考えがちです。
> 「登録ボタンを押すと、なぜか従業員一覧画面に行ってしまうな……。よし、Controllerの `insert` メソッドの戻り値を、ログイン画面のHTMLである `return "administrator/login";` に書き換えればいいんだな！」

**ここで、ボス（指導者）はストップをかけます。**

## 2. 指導者からの「気づき」の問いかけ
研修生に以下のように問いかけてみてください。
> 「確かに `return "administrator/login";` と書けばログイン画面は表示されるね。でも、ブラウザのアドレスバー（URL）を見てごらん？ `/insert` のままになっていないかな？ この状態で、ユーザーがブラウザの『更新ボタン（F5）』を押したら、どうなると思う？」

研修生に「更新＝さっきの通信（登録処理）をもう一度送ることになる」という二重送信のリスク（1-4に関連）に気づかせます。

## 3. ロジックの組み立て方：PRGパターン
Web開発の鉄則である **PRG（Post - Redirect - Get）パターン** を教えます。

- **P (Post)**: ユーザーがフォームを「送信」する。
- **R (Redirect)**: サーバーが登録処理を終えたら、「あの画面へ移動してね」と「命令」を返す。
- **G (Get)**: ブラウザが命令に従い、新しい画面を「取得」しにいく。

「表示するHTMLを指定するのではなく、**『別のURLへ移動しろ』という命令**を返さなきゃいけないんだよ」とロジックを導きます。

## 4. メソッド・文法の駆使（実際のコード）

### Controllerクラスの修正
```java
@PostMapping("/insert")
public String insert(InsertAdministratorForm form) {
    // ...インサート処理...
    
    // 修正前: return "employee/list";
    // 正解の修正:
    return "redirect:/"; 
}
```

- **解説**:
    - Spring Bootでは、戻り値の文字列の先頭に `redirect:` と書くだけで、ブラウザへの「移動命令（ステータスコード302）」になります。
    - `/` はログイン画面のURLパスなので、これで安全にログイン画面へ移動（リダイレクト）できます。

## 5. さらなるUX向上（フラッシュメッセージ）
「ただ移動させるだけじゃ不親切だよね。登録できたのか不安になるから、『登録完了しました』って出してあげよう。」と提案します。
ここで、**`RedirectAttributes`** が登場します。

### Controllerの追加修正
```java
@PostMapping("/insert")
// 引数に RedirectAttributes を追加
public String insert(InsertAdministratorForm form, RedirectAttributes redirectAttributes) {
    // ...インサート処理...
    
    // フラッシュメッセージを預ける
    redirectAttributes.addFlashAttribute("infoMessage", "登録が完了しました。ログインしてください。");

    return "redirect:/"; 
}
```

- **文法解説（RedirectAttributes）**:
    - リダイレクトをすると一度通信が切れるため、通常の `Model` では次の画面に値を渡せません。
    - `RedirectAttributes` は、次の画面まで「一回限りメッセージを運んでくれる宅急便」のような役割をします。

### HTML側（ログイン画面）の追加
ログイン画面（`administrator/login.html`）の目立つ場所に、メッセージを表示するエリアを作ります。

```html
<!-- infoMessage がある時だけ表示する -->
<div th:if="${infoMessage}" class="alert alert-info">
    <span th:text="${infoMessage}">ここにメッセージが出ます</span>
</div>
```

- **文法解説（th:if）**:
    - `th:if` は、条件が `true`（中身がある）の時だけそのタグを表示します。
    - これにより、「普通にログイン画面に来た時」には何も出さず、「登録完了後だけ」メッセージを出すという制御が一行で完結します。
