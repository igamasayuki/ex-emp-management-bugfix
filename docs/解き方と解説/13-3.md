## 3. ロジックの組み立て方

**サーバー処理は不要**（JavaScript のみで可）。

1. 各行に `<input type="checkbox" class="emp-check">`
2. 全選択ボタンで `.emp-check` を `checked = true`
3. 選択解除で `false`
4. `change` で件数表示を更新

---

## 4. メソッド・文法の駆使（概要）

```html
<button type="button" id="selectAll">全選択</button>
<span id="selectedCount">選択中: 0 件</span>
```

```javascript
document.getElementById('selectAll').onclick = function () {
  document.querySelectorAll('.emp-check').forEach(function (cb) { cb.checked = true; });
  updateCount();
};
```

## 7. 付録：コード1行ずつ解説

### 7.1 HTML（list.html 59〜62, 87行）

```html
<button type="button" id="selectAll" class="btn btn-default btn-sm">全選択</button>
```
| 意味 |
|------|
| `type="button"` | フォーム送信しない（検索フォームと別） |

```html
<span id="selectedCount" class="text-muted">選択中: 0 件</span>
<span class="text-muted">（現在ページのみ）</span>
```
| 意味 |
|------|
| 件数表示＋講師確定の注釈 |

```html
<input type="checkbox" class="emp-check" th:value="${employee.id}"/>
```
| 部分 | 意味 |
|------|------|
| `class="emp-check"` | JS でまとめて操作する目印 |
| `th:each` の行ごと | **現在ページの行だけ** に存在 |

---

### 7.2 JavaScript（115行〜）

```javascript
function updateCount() {
  var n = document.querySelectorAll('.emp-check:checked').length;
  document.getElementById('selectedCount').textContent = '選択中: ' + n + ' 件';
}
```
| 行 | 意味 |
|----|------|
| `:checked` | チェックが付いているものだけ数える |
| `textContent` | 表示を更新 |

```javascript
document.getElementById('selectAll').onclick = function () {
  document.querySelectorAll('.emp-check').forEach(function (cb) { cb.checked = true; });
  updateCount();
};
```
| 意味 |
|------|
| **DOM 上の** `.emp-check` 全部＝今ページの行のみ |

```javascript
document.querySelectorAll('.emp-check').forEach(function (cb) {
  cb.addEventListener('change', updateCount);
});
```
| 意味 |
|------|
| 1つずつ手でチェックしたときも件数を更新 |
