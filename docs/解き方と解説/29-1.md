# (29-1) 初級 複数条件検索 徹底解説

> **合格ライン**: [02_レビュー判定基準.md](../02_レビュー判定基準.md) の **(29-1)**  
> **6-2 を拡張**。11-1 と **案 A** で同一 `showList`

---

## 1. 研修生のスタート地点

6-2 で名前のみ部分一致検索はできている。

> 「`/searchMail` を別 URL で作ればいいですよね？」

**指導者**: **`showList` 1本** で `name` `mail` `telephone` を受け、AND + LIKE。

---

## 2. 指導者からの問いかけ

> 「空欄の条件は検索に含めないには？」

→ `WHERE 1=1` + 入力がある項目だけ `AND`。

> 「0件のとき、6-2 と同じフォールバックは？」

→ 「１件もありませんでした」＋全件表示。

---

## 3. ロジックの組み立て方

1. 検索フォームを3欄に
2. `GET showList?name=&mail=&telephone=`
3. Repository で動的 WHERE
4. 0件なら message + 条件クリアして再取得
5. 11-1: 同じ `showList` で sort/page 併用

---

## 4. メソッド・文法の駆使（概要）

```java
if (hasSearchCriteria(...) && employeeService.getCount(...) == 0) {
    model.addAttribute("message", "１件もありませんでした");
    name = mail = telephone = null;
}
```

```java
if (name != null && !name.isEmpty()) {
    sql.append(" AND name LIKE :name");
    param.addValue("name", "%" + name + "%");
}
```

## 5. よくある誤解

| 実装 | 判定 |
|------|------|
| OR 結合のみ | 要望は AND |
| 0件で空一覧のまま | 6-2 フォールバック必要 |
| 検索とソートが別 URL | 案 A では統合推奨 |

## 6. 変更箇所の差分

`list.html` 検索3欄。`showList` にパラメータ追加。`count` / `findPage` に検索条件。

## 7. 付録：コード1行ずつ解説

### 7.1 hasSearchCriteria（55〜58行）

```java
return (name != null && !name.isEmpty())
        || (mail != null && !mail.isEmpty())
        || (telephone != null && !telephone.isEmpty());
```
| 意味 |
|------|
| **1つでも** 検索欄に入力があれば「検索モード」 |

---

### 7.2 0件フォールバック（92〜97行）

```java
if (hasSearchCriteria(name, mail, telephone) && employeeService.getCount(name, mail, telephone) == 0) {
    model.addAttribute("message", "１件もありませんでした");
    name = null;
    mail = null;
    telephone = null;
}
```
| 行 | 意味 |
|----|------|
| 検索したのに0件 | 6-2 と同じ UX |
| 3項目 null | 以降の SQL は **全件** 扱い |

---

### 7.3 Repository appendSearchConditions

```java
if (name != null && !name.isEmpty()) {
    sql.append(" AND name LIKE :name");
    param.addValue("name", "%" + name + "%");
}
```
| 部分 | 意味 |
|------|------|
| `AND` | 複数条件は **すべて満たす** |
| `%...%` | 部分一致（6-2 復習） |
| mail, telephone も同様 | 29-1 の3項目 |

---

### 7.4 list.html 検索フォーム

```html
<form method="get" th:action="@{/beyondEmployee/showList}">
```
| 意味 |
|------|
| **GET** で `showList` に直接（別 `/search` 不要） |

```html
<input type="hidden" name="sort" th:value="${sort}"/>
```
| 意味 |
|------|
| 検索実行時も **今のソートを維持**（11-1 連携） |
