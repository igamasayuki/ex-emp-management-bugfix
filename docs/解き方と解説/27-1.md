# (27-1) 初級 操作完了メッセージ 徹底解説

> **合格ライン**: [02_レビュー判定基準.md](../02_レビュー判定基準.md) の **(27-1)**  
> **1-1 の横展開**。8-1 / 9-1 とセットで実装すると効率的

---

## 1. 研修生のスタート地点

1-1 で管理者登録後の Flash はあるが、従業員の **登録・更新・削除** にはメッセージが無いことが多い。

> 「更新したら詳細に戻すだけで十分じゃないですか？」

**指導者**: 「保存されたか不安になる。**一度だけ** 伝える仕組みを揃えよう。」

---

## 2. 指導者からの問いかけ

> 「`Model.addAttribute` で渡したメッセージを F5 したらまた出る。1-1 の『一回限りの宅急便』は？」

→ **`RedirectAttributes.addFlashAttribute`**。

---

## 3. ロジックの組み立て方

| 操作 | redirect 先 | メッセージ例 |
|------|-------------|--------------|
| 従業員登録 | 一覧 | 従業員を登録しました |
| 従業員更新（8-1） | **詳細** | 従業員情報を更新しました |
| 従業員削除（9-1） | 一覧 | 従業員を削除しました |

---

## 4. メソッド・文法の駆使（概要）

```java
redirectAttributes.addFlashAttribute("successMessage", "employee.update.success");
return "redirect:/employee/showDetail?id=" + form.getId();
```

```html
<div th:if="${successMessage}" class="alert alert-success">
    <span th:text="#{${successMessage}}">完了</span>
</div>
```

---

## 5. よくある誤解

| 実装 | 判定 |
|------|------|
| `Model` のみ（redirect なし） | Flash にならない |
| redirect 後も F5 で毎回表示 | Flash 未使用 |
| 更新後一覧のみでメッセージ | 8-1 と併用時は詳細でも可 |

---

## 6. 変更箇所の差分

各 `insert` / `update` / `delete` に `RedirectAttributes` と Flash。先画面に `th:if="${successMessage}"`。

---

## 7. 付録：コード1行ずつ解説

### 7.1 Controller（8-1 更新の例 144〜145行）

```java
redirectAttributes.addFlashAttribute("successMessage", "employee.update.success");
```
| 部分 | 意味 |
|------|------|
| `RedirectAttributes` | redirect **専用** の荷物入れ |
| `addFlashAttribute` | **次の1回の GET だけ** 有効 |
| `"successMessage"` | 画面側の `${successMessage}` と一致 |
| `"employee.update.success"` | 30-1 の messages.properties のキー |

```java
return "redirect:/beyondEmployee/showDetail?id=" + form.getId();
```
| 意味 |
|------|
| Flash は **この redirect 先** の GET で表示される（detail.html） |

---

### 7.2 登録・削除（203, 159行）

```java
redirectAttributes.addFlashAttribute("successMessage", "employee.insert.success");
return "redirect:/beyondEmployee/showList";
```
| 意味 |
|------|
| 一覧が Flash の表示先 |

---

### 7.3 detail.html / list.html

```html
<div th:if="${successMessage}" class="alert alert-success">
    <span th:text="#{${successMessage}}">完了</span>
</div>
```
| 行 | 意味 |
|----|------|
| `th:if` | キーがあるときだけ表示 |
| `#{${successMessage}}` | キーを messages から解決（30-1） |

---
