# (30-1) 初級 メッセージ外部化 徹底解説

> **合格ライン**: [02_レビュー判定基準.md](../02_レビュー判定基準.md) の **(30-1)**  
> **18-1 より先**に実施すると効率的（05 確定）

---

## 1. 研修生のスタート地点

Flash やラベルが HTML・Java に直書き。

> 「日本語のまま properties にコピーすれば多言語完了ですよね？」

**指導者**: 今回は **外部化の準備**。キー設計と `th:text="#{...}"` が目的。

---

## 2. 指導者からの問いかけ

> 「『登録しました』が5箇所にあったら、文言変更のたびに5回直す？」

→ `messages.properties` に **1箇所**。

---

## 3. ロジックの組み立て方

1. `src/main/resources/messages.properties` 作成
2. `application.yml` に `spring.messages.basename`
3. Flash は **キー** を渡す
4. HTML は `th:text="#{キー}"` または `th:text="#{${successMessage}}"`

---

## 4. メソッド・文法の駆使（概要）

```properties
employee.update.success=従業員情報を更新しました
```

```yaml
spring:
  messages:
    basename: messages
    encoding: UTF-8
```

```html
<span th:text="#{${successMessage}}"></span>
```

---

## 6. 変更箇所の差分

---

## 7. 付録：コード1行ずつ解説

### 7.1 messages.properties

```properties
employee.insert.success=従業員を登録しました
```
| 部分 | 意味 |
|------|------|
| `employee.insert.success` | **キー**（英数字・ドット） |
| `=` の右 | 画面に出す **値**（日本語） |

---

### 7.2 application.yml

```yaml
spring:
  messages:
    basename: messages
```
| 意味 |
|------|
| `messages.properties` を読み込む（拡張子不要） |

```yaml
    encoding: UTF-8
```
| 意味 |
|------|
| 日本語の文字化け防止 |

---

### 7.3 Controller

```java
redirectAttributes.addFlashAttribute("successMessage", "employee.update.success");
```
| 意味 |
|------|
| 文言そのものではなく **キー** を Flash に載せる |

---

### 7.4 HTML

```html
<span th:text="#{${successMessage}}">完了</span>
```
| 部分 | 意味 |
|------|------|
| `#{}` | messages から取得 |
| `${successMessage}` | Flash のキー名を動的に指定 |
