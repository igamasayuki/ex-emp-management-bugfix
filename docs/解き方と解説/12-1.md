# (12-1) 初級 ログ出力 徹底解説

> **合格ライン**: [02_レビュー判定基準.md](../02_レビュー判定基準.md) の **(12-1)**  
> **講師用完成形**: `step5_beyond`（SLF4J） / **研修生**: 本番各クラスへ追記

---

## 1. 研修生のスタート地点

`System.out.println` だけ、またはログが無い。

> 「`e.printStackTrace()` すればログですよね？」

**指導者**: 本番は **SLF4J + Logback**。レベル（INFO / ERROR）と **パスワードを出さない** ことを教える。

---

## 2. 指導者からの問いかけ

> 「ログイン成功を DEBUG にすると本番で埋もれない？ お客様は INFO で欲しい処理は？」

→ ログイン・登録・更新・削除の **成功 = INFO**。

> 「パスワードやメール全文をログに書いたら？」

→ **Must not**。ID や操作種別程度に。

---

## 3. ロジックの組み立て方

1. クラス先頭に `private static final Logger log = LoggerFactory.getLogger(...);`
2. 成功時 `log.info("...", id);`
3. catch で `log.error("...", id, e);`（第2引数に例外でスタックトレース）

---

## 4. メソッド・文法の駆使（概要）

```java
private static final Logger log = LoggerFactory.getLogger(BeyondEmployeeService.class);

log.info("従業員を更新しました id={}", employee.getId());
log.error("従業員更新に失敗しました id={}", id, e);
```

---

## 5. よくある誤解

| 実装 | 判定 |
|------|------|
| `System.out.println` のみ | 不十分 |
| パスワード平文ログ | Must not |
| ERROR なのにスタックトレースなし | 不十分 |

| `EmployeeService` | insert/update/delete の INFO |

## 7. 付録：コード1行ずつ解説

### 7.1 Logger の宣言（Service 24〜25行）

```java
private static final Logger log = LoggerFactory.getLogger(BeyondEmployeeService.class);
```

| 部分 | 意味 |
|------|------|
| `static final` | クラスにつき1つ |
| `LoggerFactory.getLogger(このクラス.class)` | ログに **クラス名** が付く |
| `BeyondEmployeeService.class` | どのクラスのログか識別 |

---

### 7.2 INFO（成功）

```java
log.info("従業員を登録しました id={}", employee.getId());
```

| 部分 | 意味 |
|------|------|
| `info` | 正常系の記録 |
| `{}` | 後ろの引数が埋め込まれる（`+` 連結より安全） |
| `employee.getId()` | 個人特定は ID 程度 |

同様に `update` / `delete` / `login` / `register` に INFO。

---

### 7.3 ERROR（失敗）

```java
log.error("従業員更新に失敗しました id={}", form.getId(), e);
```

| 部分 | 意味 |
|------|------|
| `error` | 異常系 |
| 最後の `e` | **例外オブジェクト**。スタックトレース付きで出力 |
| Controller の catch | ユーザーには画面、開発者にはログ |

```java
log.error("画像ファイルの削除に失敗しました file={}", imageFileName, e);
```

| 意味 |
|------|
| 9-1 の画像削除失敗も ERROR（処理は続行） |

---

## 10. まとめ

> 「INFO で何が起きたか、ERROR でなぜ失敗したか。秘密情報は書かない。」
