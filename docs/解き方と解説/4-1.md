# (4-1) 初級 日付フォーマット 徹底解説

## 1. 研修生のスタート地点（バグの状態）
研修生は、画面に表示されている `2016-12-01 00:00:00.0` のような見栄えの悪い日付を見て以下のように考えます。
> 「ミリ秒まで出ちゃってるな……。よし、JavaのControllerやDomain（Entity）クラスの中で `SimpleDateFormat` を使って、文字列の `2016年12月01日` に変換してからHTMLに渡そう！」

**ここで、ボス（指導者）は「レイヤーの責務（役割分担）」を教えます。**

## 2. 指導者からの「気づき」の問いかけ
研修生に以下のように問いかけてみてください。
> 「Java側で『2016年12月01日』という文字列に変換しちゃうと、もし後から『英語圏のユーザー向けに 2016/12/01 って表示したい』って言われたら、Javaのコードから直しに行かないといけなくなるね。データをどう『見せる』かって、誰の仕事だろう？」

研修生に、**「データ（Java）は見せる形に関与しない。見た目の装飾は画面（Thymeleaf）の仕事である」**というMVCパターンの基本を意識させます。

## 3. ロジックの組み立て方：Thymeleafのユーティリティ活用
「Javaからは純粋な日付データ（Date型）のまま渡して、HTMLを描画するThymeleafの機能を使って化粧をしよう」と導きます。

1.  **Java側**: 何もしない（Date型のまま `Model` に詰める）。
2.  **HTML側**: Thymeleafの `#dates` オブジェクトを使ってフォーマットを指定する。

## 4. メソッド・文法の駆使（実際のコード）

### HTML側（list.html / detail.html）の修正
```html
<!-- 修正前 -->
<span th:text="${employee.hireDate}">2016-12-01 00:00:00.0</span>

<!-- 正解の修正 -->
<span th:text="${#dates.format(employee.hireDate, 'yyyy年MM月dd日')}">2016年12月01日</span>
```

- **文法解説（#dates ユーティリティ）**:
    - `#dates` はThymeleafが用意してくれている、日付操作専用の道具箱（ユーティリティオブジェクト）です。
    - `.format(対象の変数, 'フォーマット文字列')` と書くことで、Javaの `SimpleDateFormat` と同じように日付を好きな形に整形できます。
    - `yyyy`（年）、`MM`（月 ※大文字）、`dd`（日）のルールも合わせて教えると親切です。

## 5. 研修生へのステップアップ課題
「じゃあ、この要領で『給料』の数字もカンマ区切り（例：233,800円）にしてみたいんだけど、日付に `#dates` があるなら、数字にはどんな道具箱（ユーティリティ）があると思う？」

と問いかけ、次の課題である **(4-2) 価格フォーマット** への伏線を張ります。
（※答えは `#numbers` です。）

## 6. まとめ：研修生に伝えたいメッセージ
> 「バックエンド（Java）は『純粋なデータ』を扱う。フロントエンド（HTML）は『見せ方』を扱う。この役割をしっかり分けることが、将来の仕様変更に強い、綺麗なシステムを作るコツだよ。」
