# (22-1) 初級 パスワード変更 徹底解説

> **合格ライン**: [02_レビュー判定基準.md](../02_レビュー判定基準.md) の **(22-1)**  
> **5-4 BCrypt** 完了後が前提

---

## 1. 研修生のスタート地点

パスワード変更画面は無い。

> 「新パスワードを DB にそのまま UPDATE すればいいですよね？」

**指導者**: **平文禁止**。`matches` で現在確認 → `encode` で保存 → **ログアウト**。

---

## 2. 指導者からの問いかけ

> 「1-5 の確認用パスワードと同じ理由で確認欄が要る？」

→ 新パスワードと確認用の一致。

> 「変更 URL を未ログインで開いたら？」

→ セッション（`administratorMail`）チェック。

---

## 3. ロジックの組み立て方

1. `header` にリンク
2. `BeyondChangePasswordForm`
3. GET/POST `/changePassword`
4. Service: `matches` → `encode` → UPDATE
5. 成功: `session.invalidate()` + redirect + Flash

---

## 4. メソッド・文法の駆使（概要）

```java
administratorService.changePassword(mail, currentRaw, newRaw);
session.invalidate();
redirectAttributes.addFlashAttribute("infoMessage", "password.change.success");
return "redirect:/beyond/";
```

---

## 5. よくある誤解

| 実装 | 判定 |
|------|------|
| 平文で UPDATE | Must not |
| 変更後も旧セッションのまま | 再ログイン促す |

---

## 6. 変更箇所の差分

新規 Controller/Form/テンプレート。`AdministratorRepository#updatePassword`。header にリンク。

---

## 7. 付録：コード1行ずつ解説

### 7.1 GET changePassword（38〜43行）

```java
if (session.getAttribute("administratorMail") == null) {
    return "redirect:/beyond/";
}
```
| 意味 |
|------|
| 未ログインは **変更画面を見せない** |

---

### 7.2 POST（55〜57, 63〜66行）

```java
if (!form.getNewPassword().equals(form.getNewPasswordConfirm())) {
    result.rejectValue("newPasswordConfirm", null, "パスワードが一致しません");
}
```
| 意味 |
|------|
| 1-5 と同型の **確認用一致**（Form だけでは自動不可） |

```java
administratorService.changePassword(mail, form.getCurrentPassword(), form.getNewPassword());
session.invalidate();
redirectAttributes.addFlashAttribute("infoMessage", "password.change.success");
```
| 行 | 意味 |
|----|------|
| changePassword | 下記 Service |
| invalidate | 古いログイン状態を破棄 |
| Flash | ログイン画面で再ログインを促す |

---

### 7.3 Service changePassword

```java
if (admin == null || !passwordEncoder.matches(currentRaw, admin.getPassword())) {
    throw new IllegalArgumentException("現在のパスワードが正しくありません");
}
```
| 部分 | 意味 |
|------|------|
| `matches(平文, ハッシュ)` | 5-4 復習。DB から平文は取れない |
| 失敗時例外 | Controller で `rejectValue` |

```java
administratorRepository.updatePassword(mailAddress, passwordEncoder.encode(newRaw));
```
| 意味 |
|------|
| 新パスワードを **ハッシュ化して** UPDATE |
