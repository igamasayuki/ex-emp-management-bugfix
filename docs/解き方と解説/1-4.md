# (1-4) 初級 ダブルサブミット対策 徹底解説

> **合格ライン**: 判定は [02_レビュー判定基準.md](../02_レビュー判定基準.md) の **(1-4)** / 別解は [03_別解・許容一覧.md](../03_別解・許容一覧.md) を参照。

## 1. 研修生のスタート地点（バグの状態）
研修生は、(1-1) でリダイレクトを実装したことで、満足してしまいがちです。
> 「登録後にログイン画面へリダイレクトするようにしたから、これで完璧だ。更新ボタン（F5）を押しても大丈夫だし！」

**ここで、ボス（指導者）は「さらなる意地悪なユーザー」の動きを提示します。**

## 2. 指導者からの「気づき」の問いかけ
研修生に以下のように問いかけてみてください。
> 「更新ボタンは防げたね。じゃあ、登録ボタンを**『マウスで高速ダブルクリック』**したり、送信中に連打されたらどうなると思う？ 通信が終わる前に2回目のリクエストが飛んじゃわないかな？」

研修生に、バックエンド（サーバー）だけでは防ぎきれない「物理的な連打」という問題に気づかせます。

## 3. ロジックの組み立て方：二段構えの防御
「ダブルサブミット（二重送信）」を防ぐには、バックエンドとフロントエンドの両方で対策する「二段構え」がプロの鉄則であることを教えます。

1.  **【一段目】バックエンド（PRGパターン）**: (1-1) で実装した `redirect:` です。完了後に「移動」させることで、ブラウザの更新による再送信を防ぎます。
2.  **【二段目】フロントエンド（JavaScript）**: ボタンを押した瞬間に「物理的に押せなくする」対策です。これにより、連打自体を封じ込めます。

## 4. メソッド・文法の駆使（実際のコード）

### HTML側（insert.html）の修正
```html
<!-- onsubmit でボタンを非活性化するロジックを追加 -->
<form method="post" th:action="@{/insert}" 
      onsubmit="document.getElementById('registerBtn').disabled=true;">
    
    <!-- 登録ボタンに ID を付与 -->
    <button type="submit" id="registerBtn" class="btn btn-primary">登録</button>
</form>
```

- **文法解説（onsubmit）**:
    - フォームの送信が確定した瞬間に実行されるイベントです。
    - `document.getElementById('registerBtn').disabled=true;` という一行のJavaScriptを書くだけで、ボタンがグレーアウトして押せなくなります。
    - 「通信が始まった瞬間に鍵をかける」というイメージを伝えます。

## 5. 研修生へのステップアップ課題
「もし入力エラーがあった場合にボタンが消えたままだと、ユーザーは修正して再送できなくなっちゃうよね？ Spring Bootのフォワード（エラー画面の返却）なら画面が再描画されるからボタンは元に戻るけど、もしもっと高度な非同期通信（Ajax）を使う場合はどうすればいいと思う？」

といった、より高度な技術への興味を持たせるフックを作ります。

## 6. まとめ：研修生に伝えたいメッセージ
> 「ユーザーの操作は常に予想外だよ。バックエンドで論理的に守り、フロントエンドで物理的に守る。この『多層防御』の考え方が、システムの信頼性を決めるんだ。」

## 変更箇所の差分（修正前 → 修正後）

### `AdministratorController.java` — PRG（1-1 と共通）

**修正前**: `return "employee/list";`  
**修正後**: `return "redirect:/";`  
→ 登録成功後の **F5 再送信** を防ぐのはこちら。

### `administrator/insert.html` — ダブルクリック対策

**修正前**

```html
<form method="post" th:action="@{/insert}" th:object="${insertAdministratorForm}">
    …
    <button type="submit" class="btn btn-primary">登録</button>
</form>
```

**修正後**

```html
<form method="post" th:action="@{/insert}" th:object="${insertAdministratorForm}"
      onsubmit="document.getElementById('registerBtn').disabled=true;">
    …
    <button type="submit" id="registerBtn" class="btn btn-primary">登録</button>
</form>
```
