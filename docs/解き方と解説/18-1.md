## 1. 研修生のスタート地点

Form に `message="..."` はあるが、注解省略時に英語が混ざる。

> 「全部 Form の message 属性に書けばいいですよね？」

**指導者**: 標準キーを **properties で一括管理**。

---

## 2. 指導者からの問いかけ

> 「`@NotBlank` だけ付けて message を省略したら、何語で出る？」

→ デフォルト英語 → properties で日本語化。

## 3. ロジックの組み立て方

1. 30-1 で `spring.messages` 有効化済み
2. `messages.properties` に Validation 用キー追加
3. Form の冗長な `message=` を整理（任意）

## 7. 付録：コード1行ずつ解説

### 7.1 messages.properties（13〜16行）

```properties
jakarta.validation.constraints.NotBlank.message=入力必須です
```
| 部分 | 意味 |
|------|------|
| `jakarta.validation.constraints.NotBlank` | Bean Validation が参照する **標準キー** |
| `.message` | メッセージ本文のサフィックス |

```properties
jakarta.validation.constraints.Email.message=メールアドレスの形式が不正です
```
| 意味 |
|------|
| `@Email` 違反時の既定文言を上書き |

---

### 7.2 Form（BeyondUpdateEmployeeForm）

```java
@NotBlank(message = "名前を入力してください")
private String name;
```
| パターン | 意味 |
|----------|------|
| `message` 直書き | 動く。優先度高い |
| `@NotBlank` のみ | properties の既定メッセージを使用 |

研修では **どちらかに統一** すればよい。

---

### 7.3 画面表示

```html
<label th:errors="*{name}" class="error-messages"></label>
```
| 意味 |
|------|
| バリデーション結果（日本語）がここに出る |
