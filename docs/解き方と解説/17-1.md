## 1. 研修生のスタート地点

7-1 で Service の Mockito テストはあるが、Repository はモックのまま。

> 「Repository も `@Mock` すればいいですよね？」

**指導者**: 17-1 の Must は **実 PostgreSQL** で SQL が正しいか確認すること。

---

## 2. 指導者からの問いかけ

> 「テストが互いのデータに依存したら、順番を変えただけで落ちるよね？」

→ `@Transactional` でロールバック、または `@BeforeEach` で掃除。

> 「本番 DB をそのまま使う？」

→ **test 用 DB** + `application-test.yml`（講師配布）。

---

## 3. ロジックの組み立て方

1. `src/test/resources/application-test.yml`
2. `@SpringBootTest` `@ActiveProfiles("test")`
3. `@Qualifier("beyondEmployeeRepository")` で step5 の Bean を注入（本番なら通常の Repository）
4. insert → load → update → delete を検証

---

## 4. メソッド・文法の駆使（概要）

```java
@SpringBootTest
@ActiveProfiles("test")
@Transactional
class BeyondEmployeeRepositoryTest {
    @Autowired
    @Qualifier("beyondEmployeeRepository")
    private BeyondEmployeeRepository employeeRepository;
}
```

## 7. 付録：コード1行ずつ解説

### 7.1 クラス注解（19〜21行）

```java
@SpringBootTest
```
| 意味 |
|------|
| Spring Boot の **コンテキストごと** 起動してテスト |

```java
@ActiveProfiles("test")
```
| 意味 |
|------|
| `application-test.yml` を読む（講師配布の接続先） |

```java
@Transactional
```
| 意味 |
|------|
| テストメソッド終了後に **ロールバック**（DB を汚しにくい） |

---

### 7.2 注入（24〜26行）

```java
@Autowired
@Qualifier("beyondEmployeeRepository")
private BeyondEmployeeRepository employeeRepository;
```
| 部分 | 意味 |
|------|------|
| `@Qualifier` | 本番用 `EmployeeRepository` と **名前が被る** ため step5 用を指定 |
| 研修生 | 本番だけなら `@Autowired EmployeeRepository` で可 |

---

### 7.3 insertLoadUpdateDelete テスト（29〜48行）

```java
Employee employee = sampleEmployee("step5-test-" + System.nanoTime());
```
| 意味 |
|------|
| **一意な名前** で他テストと衝突しにくく |

```java
if (maxId == null) {
    employee.setId(1);
} else {
    employee.setId(maxId + 1);
}
employeeRepository.insert(employee);
```
| 意味 |
|------|
| テストデータを **自分で INSERT**（準備） |

```java
Employee loaded = employeeRepository.load(employee.getId());
assertThat(loaded.getName()).isEqualTo(employee.getName());
```
| 意味 |
|------|
| insert 後に **読める** ことを確認 |

```java
employeeRepository.deleteById(employee.getId());
assertThat(page.stream().noneMatch(e -> e.getId().equals(employee.getId()))).isTrue();
```
| 意味 |
|------|
| delete 後に **いない** ことを確認（クリーンアップ兼ねる） |
