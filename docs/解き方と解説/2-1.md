# (2-1) 中級 ログイン者名表示 徹底解説

> **合格ライン**: 判定は [02_レビュー判定基準.md](../02_レビュー判定基準.md) の **(2-1)** / 別解は [03_別解・許容一覧.md](../03_別解・許容一覧.md) を参照。

## 1. 研修生のスタート地点（バグの状態）
研修生は、ログイン後の画面に名前を表示しようとして、以下のように考えます。
> 「ログインに成功したんだから、その時の `Administrator` オブジェクトから名前を取って `Model` に入れればいいんだな。……あれ？ でも、一覧画面から詳細画面に移動したら、名前が消えちゃったぞ？ 全てのメソッドで `Model` に入れ直さなきゃいけないの？」

**ここで、ボス（指導者）は「情報の賞味期限」と「共有」の概念を教えます。**

## 2. 指導者からの「気づき」の問いかけ
研修生に以下のように問いかけてみてください。
> 「`Model` は、今から表示する『その一画面だけ』のための使い捨ての箱なんだ。でも、ログインした人の名前は、ログアウトするまでずっと覚えておいてほしいよね。ブラウザを閉じたり移動したりしても、サーバーが『あ、君はさっきの〇〇さんだね』と認識し続けるための特別な場所があるんだけど、知ってるかな？」

研修生に、リクエストをまたいで情報を保持する「Session（セッション）」の必要性を気づかせます。

## 3. ロジックの組み立て方：セッションと共通部品
「ずっと使うデータはセッションに入れよう。そして、全画面で使う見た目は一箇所にまとめよう」という、メンテナンス性を重視した設計を導きます。

1.  **ログイン時にセッションへ保存**: `session.setAttribute("name", ...)`。
2.  **共通の見た目（ヘッダー）を作る**: 全画面で共有するHTMLを切り出す。
3.  **セッションから名前を取り出す**: HTML側で `${session.name}` と書いて表示する。

## 4. メソッド・文法の駆使（実際のコード）

### Controllerでの保存（MiddleAdministratorController.java）
```java
@Autowired
private HttpSession session; // セッションを使えるようにする

@PostMapping("/login")
public String login(LoginForm form, RedirectAttributes redirectAttributes) {
    Administrator administrator = administratorService.login(...);
    if (administrator != null) {
        // (2-1) ログインに成功したら、名前をセッション（共有ロッカー）に入れる
        session.setAttribute("administratorName", administrator.getName());
        return "redirect:/employee/showList";
    }
    // ...
}
```

- **文法解説（HttpSession）**:
    - 「サーバー側にある、ユーザーごとの専用ロッカー」だとイメージさせます。
    - ここに入れたデータは、ブラウザを閉じるかタイムアウトするまで、どのURLにアクセスしても取り出すことができます。

### HTML共通部品の作成（common/header.html）
```html
<!-- th:fragment でこの部分に「header」という名前を付ける -->
<nav th:fragment="header" class="navbar navbar-default">
    ...
    <p class="navbar-text navbar-right">
        <!-- セッションから名前を取り出して表示 -->
        <span th:text="${session.administratorName} + 'さん こんにちは！'"></span>
    </p>
    ...
</nav>
```

- **文法解説（th:fragment）**:
    - HTMLの一部を「部品」として定義するThymeleafの文法です。

### 各画面での呼び出し（list.html / detail.html）
```html
<!-- 共通部品を呼び出して、このタグと置き換える -->
<div th:replace="~{common/header :: header}"></div>
```

- **文法解説（th:replace）**:
    - 「あのファイルの、あの名前の部品を持ってきて！」という指示です。
    - これにより、今後「こんにちは」を「ようこそ」に変えたくなった時、100画面あっても `header.html` を一箇所直すだけで済むようになります。

## 5. 研修生へのステップアップ課題
「もし、悪意のあるユーザーがログインせずに `.../showList` のURLを直接叩いたら、名前はどう表示されるかな？ もしくは、エラーにならないかな？」

といった、セキュリティ（認証フィルター）や未ログイン時の考慮（nullチェック）へと視野を広げさせます。

## 6. まとめ：研修生に伝えたいメッセージ
> 「プロの仕事は、後で楽をすること（メンテナンス性）を考えること。共通化とセッションを使いこなせれば、君のアプリは一気に『システム』らしくなるよ。」

## 変更箇所の差分（修正前 → 修正後）

### `LoginSuccessHandler.java`（新規）

**修正後** — ログイン成功時にセッションへ名前を保存

```java
@Override
public void onAuthenticationSuccess(...) {
    Administrator administrator = administratorRepository.findByMailAddress(mailAddress);
    if (administrator != null) {
        request.getSession().setAttribute("administratorName", administrator.getName());
    }
    response.sendRedirect(request.getContextPath() + "/employee/showList");
}
```

### `templates/common/header.html`（新規）

**修正後**

```html
<nav th:fragment="header" class="navbar navbar-default">
    …
    <span th:if="${session.administratorName != null}">
        <span th:text="${session.administratorName} + 'さん　こんにちは！'"></span>
    </span>
</nav>
```

### `employee/list.html` / `employee/detail.html`

**修正前** — ナビ内に `${administratorName}` や固定名

```html
<span th:text="${administratorName}">山田太郎</span>さんこんにちは！
```

**修正後** — 共通ヘッダーに差し替え

```html
<div th:replace="~{common/header :: header}"></div>
```

### `WebSecurityConfig.java`

**修正後** — カスタム成功ハンドラを利用

```java
.successHandler(loginSuccessHandler)
```

## 7. 付録：コード1行ずつ解説

### 7.1 `LoginSuccessHandler`

```java
@Override
public void onAuthenticationSuccess(HttpServletRequest request, HttpServletResponse response,
        Authentication authentication) {
```

| 意味 |
|------|
| Spring Security がログイン成功時に呼ぶコールバック |

```java
    Administrator administrator = administratorRepository.findByMailAddress(mailAddress);
    if (administrator != null) {
        request.getSession().setAttribute("administratorName", administrator.getName());
    }
```

| 行 | 意味 |
|----|------|
| `getSession()` | HTTP セッション（サーバ側の記憶） |
| `setAttribute("administratorName", ...)` | 以降の画面で名前表示に使う |

```java
    response.sendRedirect(request.getContextPath() + "/employee/showList");
```

| 意味 |
|------|
| ログイン後は従業員一覧へリダイレクト |

---

### 7.2 `common/header.html`

```html
<nav th:fragment="header" class="navbar navbar-default">
```

| 意味 |
|------|
| `header` という **部品** を定義。他画面から `th:replace` で差し込む |

```html
<span th:if="${session.administratorName != null}">
    <span th:text="${session.administratorName} + 'さん　こんにちは！'"></span>
</span>
```

| 部分 | 意味 |
|------|------|
| `${session.administratorName}` | セッションに保存した名前 |
| `+ 'さん…'` | 文字列連結（Thymeleaf 式） |

---
