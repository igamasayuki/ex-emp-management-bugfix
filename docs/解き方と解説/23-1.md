# (23-1) 初級 ログアウト機能の改善 徹底解説

> **合格ライン**: [02_レビュー判定基準.md](../02_レビュー判定基準.md) の **(23-1)**  
> **講師用完成形**: `BeyondAdministratorController#logout` / **研修生**: Spring Security + login.html

---

## 1. 研修生のスタート地点

ログアウトリンクはあるが、セッションが残る・メッセージが出ないことがある。

> 「ログアウトしたら `return "administrator/login"` で画面を出せばいいですよね？」

**指導者**: Security 利用時は **セッション無効化** と **ログイン画面への redirect + Flash**。

---

## 2. 指導者からの問いかけ

> 「ログアウト後に戻るボタンで一覧が見えたら困るよね。セッションはどこで無効化する？」

→ `session.invalidate()` または Security の `logout` 設定。

> 「『ログアウトしました』は一度だけ出したい？」

→ Flash `logoutMessage`（27-1 同様）。

---

## 3. ロジックの組み立て方

1. ログアウト URL（`GET /beyond/logout` または Security `/logout`）
2. `session.invalidate()`
3. `redirect:/` ＋ Flash
4. `login.html` で `th:if="${logoutMessage}"` または `param.logout`

---

## 4. メソッド・文法の駆使（概要）

```java
@GetMapping("/logout")
public String logout(RedirectAttributes redirectAttributes) {
    session.invalidate();
    redirectAttributes.addFlashAttribute("logoutMessage", "logout.success");
    return "redirect:/beyond/";
}
```

---

## 5. よくある誤解

| 実装 | 判定 |
|------|------|
| 画面表示だけでセッション残存 | NG |
| ログアウトメッセージが毎回 F5 で出る | Flash 未使用 |

---

## 6. 変更箇所の差分

`BeyondAdministratorController` に `logout` 追加。`login.html` にメッセージ欄。

---

## 7. 付録：コード1行ずつ解説

### 7.1 logout メソッド（87〜92行）

```java
@GetMapping("/logout")
```
| 意味 |
|------|
| step5 は GET でログアウト（研修生は Security の POST `/logout` でも可） |

```java
session.invalidate();
```
| 行 | 意味 |
|----|------|
| サーバー側の **セッション全体を破棄** |
| `administratorName` 等も消える → 未ログイン状態 |

```java
redirectAttributes.addFlashAttribute("logoutMessage", "logout.success");
return "redirect:/beyond/";
```
| 意味 |
|------|
| ログイン画面へ PRG + 一度だけメッセージ |

---

### 7.2 login.html

```html
<div th:if="${logoutMessage}" class="alert alert-info">
    <span th:text="#{${logoutMessage}}">ログアウト</span>
</div>
```
| 意味 |
|------|
| Flash のキーを messages から表示（30-1） |

---

### 7.3 login 時のセッション（82〜83行）

```java
session.setAttribute("administratorName", administrator.getName());
session.setAttribute("administratorMail", administrator.getMailAddress());
```
| 意味 |
|------|
| 22-1 パスワード変更で **メール** が必要なため mail も保存 |

---
