## 2. ビルド

```bash
./gradlew bootJar
```

成果物: `build/libs/*.jar`

## 3. 配置・起動（例: JAR 直デプロイ）

```bash
scp build/libs/アプリ名.jar user@server:/path/app/
ssh user@server
java -jar -Dspring.profiles.active=prod /path/app/アプリ名.jar
```
